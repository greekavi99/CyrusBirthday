# Baby Month Photos

Add 12 photos of baby Adriel Cyrus (one from each month of his first year) to this folder.

## Required file names for Month Game:

- `month-1.jpg` (1st month)
- `month-2.jpg` (2nd month)
- `month-3.jpg` (3rd month)
- `month-4.jpg` (4th month)
- `month-5.jpg` (5th month)
- `month-6.jpg` (6th month)
- `month-7.jpg` (7th month)
- `month-8.jpg` (8th month)
- `month-9.jpg` (9th month)
- `month-10.jpg` (10th month)
- `month-11.jpg` (11th month)
- `month-12.jpg` (12th month)

The game will show each photo and ask the user to guess how old baby Adriel is!

## Required file names for Puzzle Game:

Add 5 family photos for the puzzle game:

- `family-photo-1.jpg` (Family photo 1)
- `family-photo-2.jpg` (Family photo 2)
- `family-photo-3.jpg` (Family photo 3)
- `family-photo-4.jpg` (Family photo 4)
- `family-photo-5.jpg` (Family photo 5)

Add this photo for the Pac-Man-style game:

- `son-photo.jpg` (A photo of your son to use as the moving player)

The puzzle game will randomly select one of the family photos and break it into 16 pieces (4x4 grid) that players must reassemble.
The Pac-Man-style game will use `son-photo.jpg` instead of a yellow dot for the player character.

> **Note:** Until you add real photos, the games will show emoji placeholders.
